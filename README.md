# Rock, Paper, Scissors (CLI) 🪨📄✂️

A simple Command Line Interface (CLI) Rock, Paper, Scissors game built with Dart. 

Created as part of Andrea Bizzotto's course: **"Learn Dart Programming in depth. Includes: basic to advanced topics, exercises, and projects. Fully updated to Dart 2.15"**.

## 🚀 Features
* **Game Loop:** Continuous gameplay using `while(true)`.
* **Type Safety:** Built using Dart `enum` for moves.
* **Random AI:** Opponent choices powered by `dart:math`.
* **Input Handling:** Validates choices (`r/p/s`) and exits cleanly on `q`.

## 🛠️ Concepts Applied
* Variable Scoping & Enums
* `dart:io` for Terminal I/O
* Control Flow (`if/else`, `switch`)

## 💻 How to Run
```bash
dart run rock_paper_scissors.dart
